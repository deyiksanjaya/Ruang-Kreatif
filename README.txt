RUANG KREATIF BY HERI - PAKET FILE WEBSITE

Buka index.html di browser. Semua file HTML, CSS, dan JavaScript dipisah.

FILE UTAMA:
index.html : halaman website
style.css : tampilan dan animasi
script.js : menu, kartu interaktif, dan slide
assets/hero.png : gambar hero dari versi sebelumnya (digunakan pada CSS)
assets/logo-original.jpg : logo referensi asli
assets/referensi-brand.jpg : kolase branding dari pengguna
assets/asset-board.png : papan referensi aset baru
assets/*.png : potongan gambar dari asset-board untuk pengembangan lebih lanjut

CATATAN: Beberapa ilustrasi potongan merupakan referensi visual, bukan elemen terpisah dengan transparansi. Logo dan kartu interaktif pada halaman saat ini dibuat dengan HTML/CSS, bukan gambar.

Tidak membutuhkan server atau instalasi.
